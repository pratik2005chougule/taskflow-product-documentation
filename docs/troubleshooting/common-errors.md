# Common Errors

## Overview

This article provides solutions to frequently reported TaskFlow issues.

## Invalid Username or Password

### Cause

Incorrect login credentials.

### Resolution

1. Verify your email address.
2. Re-enter your password.
3. Reset your password if necessary.

## Access Denied

### Cause

Insufficient permissions.

### Resolution

1. Contact your administrator.
2. Verify your assigned role.
3. Request required permissions.

## Project Not Visible

### Cause

The user is not assigned to the project.

### Resolution

1. Confirm project membership.
2. Request access from the project owner.

## Task Update Failure

### Cause

Network interruption or validation errors.

### Resolution

1. Refresh the page.
2. Check internet connectivity.
3. Verify required fields.

## API Authentication Failure

### Cause

Expired or invalid access token.

### Resolution

1. Generate a new token.
2. Verify authentication headers.
3. Retry the request.

## Additional Support

If the issue persists, contact your workspace administrator or support team.
