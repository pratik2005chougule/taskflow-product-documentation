# Roles and Permissions

## Overview

Roles and permissions determine what actions users can perform within a TaskFlow workspace.

Administrators can assign roles to control access to projects, tasks, and workspace settings.

## Available Roles

### Administrator

Administrators have full control over the workspace.

Capabilities include:

- Manage members
- Configure settings
- Create projects
- Delete projects
- Manage permissions
- View reports

### Project Manager

Project Managers can manage projects and tasks.

Capabilities include:

- Create projects
- Manage tasks
- Assign work
- Monitor progress
- Generate reports

### Team Member

Team Members can participate in project activities.

Capabilities include:

- View assigned projects
- Create tasks
- Update task status
- Add comments
- Upload attachments

### Viewer

Viewers have read-only access.

Capabilities include:

- View projects
- View tasks
- Access reports

## Assign Roles

1. Open Workspace Settings.
2. Select Members.
3. Choose a user.
4. Select a role.
5. Save the changes.

## Permission Best Practices

- Grant minimum required access.
- Review permissions regularly.
- Remove unnecessary privileges.
- Audit role assignments periodically.
