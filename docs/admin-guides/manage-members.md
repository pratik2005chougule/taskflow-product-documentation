# Manage Members

## Overview

Workspace administrators can manage users, control access, and maintain collaboration across projects within TaskFlow.

Member management ensures that users have appropriate access to projects and resources.

## Add a Member

To add a new member:

1. Open **Workspace Settings**.
2. Select **Members**.
3. Choose **Add Member**.
4. Enter the user's email address.
5. Assign a role.
6. Select **Send Invitation**.

The user receives an email invitation to join the workspace.

## View Members

To view existing members:

1. Open **Workspace Settings**.
2. Select **Members**.

The members list displays:

- User Name
- Email Address
- Role
- Status
- Last Activity

## Edit Member Information

To update member details:

1. Open the members list.
2. Select the user.
3. Update the required information.
4. Save the changes.

## Change Member Roles

Administrators can modify user roles as needed.

To update a role:

1. Open the member profile.
2. Select the **Role** field.
3. Choose a new role.
4. Save the changes.

Changes take effect immediately.

## Deactivate a Member

To temporarily disable access:

1. Open the member profile.
2. Select **Deactivate Member**.
3. Confirm the action.

Deactivated users cannot access the workspace until reactivated.

## Remove a Member

To permanently remove a member:

1. Open the member profile.
2. Select **Remove Member**.
3. Confirm the removal.

The user loses workspace access immediately.

## Best Practices

- Review member access regularly.
- Remove inactive users.
- Follow the principle of least privilege.
- Assign appropriate roles.
- Monitor membership changes.
