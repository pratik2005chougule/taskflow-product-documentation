# Versions Retiring in 2026

## Overview

This document lists TaskFlow product versions scheduled for retirement during 2026.

Retired versions no longer receive:

- Feature updates
- Security updates
- Bug fixes
- Technical support

Customers are encouraged to upgrade before the retirement date to ensure continued access to security improvements and product enhancements.

---

## Version Retirement Schedule

| Version | Retirement Date | Status |
|----------|----------------|---------|
| Version 0.8.x | March 31, 2026 | Retired |
| Version 0.9.x | June 30, 2026 | Retired |
| Version 1.0.x | December 31, 2026 | Scheduled |

---

## Impact of Retirement

After a version reaches retirement:

- Technical support is no longer provided.
- Security patches are not released.
- Defects are not investigated.
- Compatibility issues may arise with newer integrations.

---

## Recommended Action

Before the retirement date:

1. Review current deployment versions.
2. Plan upgrade activities.
3. Test integrations in a non-production environment.
4. Verify compatibility with custom workflows.
5. Deploy the supported release.

---

## Upgrade Planning Checklist

- Back up existing data.
- Validate system requirements.
- Review release notes.
- Test critical business processes.
- Communicate planned changes to users.
