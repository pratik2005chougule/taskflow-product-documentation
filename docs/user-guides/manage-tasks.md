# Manage Tasks

## Overview

Tasks represent individual work items within a project. Effective task management helps teams track work, meet deadlines, and improve project visibility.

## Create a Task

To create a task:

1. Open a project.
2. Select **Create Task**.
3. Enter a task title.
4. Add a task description.
5. Assign the task to a team member.
6. Set a due date.
7. Select **Save**.

## Task Information

Each task can include:

| Field | Description |
|---------|-------------|
| Title | Name of the task |
| Description | Task details and requirements |
| Assignee | Responsible team member |
| Priority | Low, Medium, or High |
| Due Date | Expected completion date |
| Status | Current progress state |

## Update a Task

To update a task:

1. Open the task.
2. Modify the required fields.
3. Save the changes.

Updates become visible to all project members.

## Change Task Status

Available statuses may include:

- To Do
- In Progress
- Under Review
- Completed
- Blocked

Keep task status updated to ensure accurate project reporting.

## Assign Tasks

To assign a task:

1. Open the task.
2. Select the **Assignee** field.
3. Select a team member.
4. Save the task.

## Set Task Priority

Task priorities help teams focus on important work.

Available priorities:

- Low
- Medium
- High
- Critical

## Delete a Task

To delete a task:

1. Open the task.
2. Select **Delete Task**.
3. Confirm the action.

Deleted tasks cannot be recovered unless backup or recovery options are available.

## Best Practices

- Create clear task titles.
- Define task requirements.
- Assign ownership.
- Set realistic deadlines.
- Review task progress regularly.
- Update task status frequently.
