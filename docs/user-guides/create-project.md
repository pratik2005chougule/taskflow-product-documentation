# Create a Project

## Overview

Projects help teams organize work, track progress, and manage deliverables within TaskFlow.

A project serves as a central location for tasks, team collaboration, files, and project-related activities.

## Before You Begin

Ensure that:

- You have permission to create projects.
- You are signed in to TaskFlow.
- You understand the project's objectives and requirements.

## Create a New Project

To create a project:

1. Open the TaskFlow dashboard.
2. Select **New Project**.
3. Enter the project name.
4. Provide a project description.
5. Select the project owner.
6. Choose a start date.
7. Specify a target completion date.
8. Select **Create Project**.

The new project is displayed in your workspace.

## Project Information

When creating a project, provide the following information:

| Field | Description |
|---------|-------------|
| Project Name | Unique project title |
| Description | Summary of project objectives |
| Owner | Person responsible for the project |
| Start Date | Project start date |
| Due Date | Expected completion date |

## Invite Team Members

To add team members:

1. Open the project.
2. Select **Members**.
3. Select **Add Member**.
4. Enter the user's email address.
5. Assign a role.
6. Save the changes.

## Update Project Details

To modify project information:

1. Open the project.
2. Select **Project Settings**.
3. Update the required fields.
4. Save the changes.

## Archive a Project

When a project is completed:

1. Open the project settings.
2. Select **Archive Project**.
3. Confirm the action.

Archived projects remain available for reference but can no longer be actively managed.

## Best Practices

- Use meaningful project names.
- Keep descriptions concise and clear.
- Assign project ownership.
- Review project status regularly.
- Archive completed projects.
